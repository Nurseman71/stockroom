Users

Each person's phone uses its own token. Turn Delete off and that phone can still browse, add and edit boxes, but it can't delete boxes or remove photos. A change reaches the phone on its next sync (within about 30 seconds).

Setting up a phone: plug it into this Mac and press Install on iPhone on that person's card. Stockroom goes onto the phone already connected as them, with nothing to type on the phone.
Reset token disconnects that one phone; press Install on iPhone again to reconnect it. Installs last about a year; installing again renews it.
